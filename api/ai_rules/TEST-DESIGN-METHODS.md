# 测试用例设计方法（核心4种 + NAS云存储增强）

本文档定义功能测试的 4 种核心设计方法，用于指导 Claude 生成专业、全面、可执行的测试用例。

> 产品语境：本仓库优先服务 **NAS 云存储 / 文件管理 / 多端同步** 类产品。生成用例时，应在通用方法基础上重点关注文件数据完整性、权限隐私、多端同步、共享协作、大文件/批量/并发、容量与系统依赖等风险。

---

## NAS 云存储产品重点测试对象

| 领域 | 重点关注 |
|------|----------|
| 文件与目录操作 | 上传、下载、复制、移动、重命名、删除、恢复、预览、搜索、筛选、排序 |
| 数据完整性 | 文件内容、大小、哈希、缩略图、转码结果、路径索引、修改时间、标签、元数据一致性 |
| 权限与共享 | 私有目录、成员权限、只读/可编辑权限、分享链接、提取码、有效期、访问范围 |
| 多端同步 | Pc / Web / Android / IOS 的状态同步、离线恢复、冲突处理、刷新时机 |
| 大文件与批量操作 | 大文件上传/下载、断点续传、批量移动/删除/恢复、深层目录树 |
| 存储与系统状态 | 容量不足、磁盘异常、索引延迟、缩略图/转码失败、网络中断、服务降级 |
| 外部与异步能力 | AI 分析、内容索引、预览转码、缩略图生成、后台任务队列、设备在线状态 |

---

## 方法选择指南

| 需求特征 | 推荐方法 |
|---------|---------|
| 有明确输入范围/格式要求 | 等价类划分 + 边界值分析 |
| 文件名、标签名、路径、备注等有长度/字符限制 | 等价类划分 + 边界值分析 |
| 涉及业务流程/多步骤操作 | 场景法 |
| 上传、下载、删除、恢复、分享等多步骤文件流程 | 场景法 |
| 文件状态会变化，如上传中、暂停、失败、完成、已删除 | 场景法 + 状态迁移测试 |
| 多角色访问，如所有者、管理员、只读成员、外链访客 | 等价类划分 + 场景法 |
| 多端同步、共享协作、并发编辑 | 场景法 + 错误推测法 |
| 大文件、批量文件、深层目录、容量限制 | 边界值分析 + 错误推测法 |
| 涉及索引、缩略图、转码、AI 分析等异步任务 | 场景法 + 数据流测试 + 错误推测法 |
| 历史缺陷多/高风险模块 | 错误推测法 + 回归场景 |
| 复杂输入组合 | 等价类划分 + 场景法 |

## 1. 等价类划分法 (Equivalence Partitioning)

### 定义

将输入数据划分为若干等价类，从每个等价类中选取代表性数据作为测试数据。同一等价类中的数据对揭露缺陷的效果是等价的。

### 分类

- **有效等价类**：符合规格说明的合理输入，程序应正确处理
- **无效等价类**：不符合规格说明的非法输入，程序应拒绝并给出提示

### 通用划分规则

| 输入条件 | 有效等价类 | 无效等价类 |
|---------|-----------|-----------|
| 取值范围 [a, b] | [a, b] 内的值 | <a 的值、>b 的值 |
| 取值集合 {A, B, C} | A、B、C 各取一个 | 非集合内的值 |
| 布尔值 | true、false | 非布尔类型值 |
| 格式要求 | 符合格式的值 | 不符合格式的值 |
| 必填项 | 非空有效值 | 空值、null、undefined、仅空格 |
| 长度限制 [m, n] | 长度在 [m, n] 内 | 长度 <m 或 >n |

### NAS 云存储等价类划分规则

| 输入/对象 | 有效等价类 | 无效等价类 |
|-----------|------------|------------|
| 文件名 | 中文、英文、数字、合法符号、合法多字节字符 | 空文件名、仅空格、包含 `/`、`\\`、`:`、`*`、`?`、`"`、`<`、`>`、`|` 等非法字符 |
| 文件名长度 | 字节数/字符数在允许范围内 | 超过最大字节数、超过最大字符数、多字节字符导致字节超限 |
| 路径 | 合法父目录、合法子目录、允许层级内路径 | 路径过长、目录层级超限、父目录不存在、循环路径 |
| 文件大小 | 允许大小范围内的文件 | 0 字节文件（若不支持）、超过单文件限制、超过剩余容量 |
| 文件类型 | 支持上传/预览的扩展名与 MIME | 扩展名伪造、MIME 不匹配、未知格式、受限格式 |
| 标签/分类 | 已存在标签、合法新标签、允许颜色值 | 重名标签、超长标签、非法字符标签、无效颜色值 |
| 权限角色 | 所有者、管理员、可编辑成员、只读成员、外链访客 | 未授权用户、权限被移除用户、过期外链用户 |
| 分享链接 | 有效链接、有效提取码、有效期内链接 | 过期链接、取消分享链接、错误提取码、无权限访问 |
| 存储容量 | 容量充足、接近上限、刚好可容纳 | 容量已满、上传后超额、配额被调整后不足 |
| 多端状态 | 在线同步、离线后恢复、弱网下重试 | 同步冲突、客户端状态滞后、重复同步、部分同步失败 |

### 用例生成原则

1. 一条用例尽可能覆盖多个**有效**等价类，减少用例数。
2. 每个**无效**等价类必须**单独**一条用例覆盖，确保定位问题。
3. NAS 场景中，文件名、路径、权限、容量、文件类型、分享状态等对象应分别划分等价类，避免只覆盖表单输入。
4. 权限类无效等价类不得合并过度：无权限、权限被移除、链接过期、提取码错误属于不同验证目标。

### 示例：文件名输入

| 等价类ID | 等价类 | 类型 | 测试数据 | 预期结果 |
|---------|-------|------|---------|---------|
| EC_FILE_01 | 合法普通字符 | 有效 | `report-2026.docx` | 创建/重命名成功 |
| EC_FILE_02 | 合法中文字符 | 有效 | `项目计划.md` | 创建/重命名成功，列表展示完整 |
| EC_FILE_03 | 合法多字节字符 | 有效 | `照片😀.jpg`（若产品允许） | 创建/重命名成功，字节长度校验正确 |
| EC_FILE_04 | 空值 | 无效 | `""` | 提示文件名不能为空 |
| EC_FILE_05 | 仅空格 | 无效 | `"   "` | 提示文件名不能为空或自动裁剪后拦截 |
| EC_FILE_06 | 非法字符 | 无效 | `a/b.txt` | 提示文件名不可包含非法字符 |
| EC_FILE_07 | 超长名称 | 无效 | 超过最大字节数的文件名 | 提示文件名超长，不创建文件 |
| EC_FILE_08 | 同目录重名 | 无效/备选 | 与已有文件同名 | 按需求提示覆盖、保留两者或阻止操作 |

### 识别模式

从需求中识别以下关键词来划分等价类：

- 范围词：`范围`、`在...之间`、`不超过`、`至少`、`最多`
- 集合词：`包括`、`仅限`、`只能是`、`可选值`
- 格式词：`格式`、`符合`、`正则`、`必须为`
- 必填词：`必填`、`必须`、`不能为空`
- 文件词：`文件名`、`目录`、`路径`、`扩展名`、`MIME`、`缩略图`、`预览`
- 权限词：`所有者`、`管理员`、`只读`、`可编辑`、`访客`、`外链`、`提取码`
- 存储词：`容量`、`配额`、`剩余空间`、`磁盘`、`存储池`、`卷`

## 2. 边界值分析法 (Boundary Value Analysis)

### 定义

对输入/输出的边界进行测试。经验表明，大量缺陷发生在边界附近。

### 边界点定义

- **上点 (On Point)**：边界上的点
- **离点 (Off Point)**：离边界最近的点（边界外侧）
- **内点 (In Point)**：域内任意一点

### 通用取值规则

| 边界类型 | 测试点 | 示例（范围 1-100） |
|---------|--------|------------------|
| [a, b] 闭区间 | a-1、a、b、b+1 | 0、1、100、101 |
| (a, b) 开区间 | a、a+1、b-1、b | 1、2、99、100 |
| [a, b) 左闭右开 | a-1、a、b-1、b | 0、1、99、100 |
| (a, b] 左开右闭 | a、a+1、b、b+1 | 1、2、100、101 |
| 最大长度 N | N-1、N、N+1 | - |
| 最小长度 M | M-1、M、M+1 | - |

### NAS 云存储常见边界

| 边界对象 | 边界点示例 |
|----------|------------|
| 文件名长度 | 1 字节、最大字节数 - 1、最大字节数、最大字节数 + 1、多字节字符临界 |
| 路径长度 | 最大路径长度 - 1、最大路径长度、最大路径长度 + 1 |
| 目录层级 | 1 层、最大层级 - 1、最大层级、最大层级 + 1 |
| 单文件大小 | 0B、1B、最大单文件大小 - 1、最大单文件大小、最大单文件大小 + 1 |
| 批量操作数量 | 0 个、1 个、最大批量数、最大批量数 + 1 |
| 标签数量 | 0 个、1 个、最大标签数、最大标签数 + 1 |
| 分享有效期 | 立即过期、最短有效期、最长有效期、超过最长有效期 |
| 回收站保留期 | 到期前、到期时、到期后 |
| 上传重试次数 | 0 次、最大重试次数、最大重试次数 + 1 |
| 剩余容量 | 刚好足够、差 1B、不足、容量为 0 |
| 搜索结果数量 | 0 条、1 条、单页最大条数、超过单页最大条数 |
| 并发客户端数量 | 1 个、最大并发数、最大并发数 + 1 |

> 注意：文件名、标签名、路径等边界应明确区分**字符数**与**字节数**。中文、emoji、组合 Unicode 字符可能导致字符数未超限但字节数超限。

### 与等价类结合使用

标准流程：

1. 先用等价类划分确定输入域。
2. 对每个等价类的边界进行边界值分析。
3. 边界值用例独立于普通等价类用例。
4. 若边界值与无效等价类的验证目标完全相同，可保留边界值更明确的用例，避免重复。

### 示例：文件名最大 255 字节

| 测试点 | 类型 | 值 | 预期结果 |
|-------|------|-----|---------|
| 最小有效值 | 上点 | 1 字节文件名 | 创建成功 |
| 上边界-1 | 内点 | 254 字节文件名 | 创建成功 |
| 上边界 | 上点 | 255 字节文件名 | 创建成功 |
| 上边界+1 | 离点 | 256 字节文件名 | 创建失败，提示文件名超长 |
| 多字节临界 | 上点/离点 | 中文或 emoji 组合后接近 255 字节 | 按字节数准确校验，不截断乱码 |

### 识别模式

从需求中识别以下关键词提取边界：

- 数值边界：`最小`、`最大`、`不超过`、`至少`、`≤`、`≥`、`<`、`>`
- 长度边界：`长度`、`字符数`、`字节`、`位数`、`最短`、`最长`
- 数量边界：`个数`、`条数`、`数量限制`、`批量`
- 存储边界：`容量`、`配额`、`剩余空间`、`单文件大小`、`上传大小`
- 时间边界：`有效期`、`保留期`、`超时`、`重试次数`

## 3. 场景法 (Scenario Testing)

### 定义

通过模拟用户实际使用场景，覆盖业务流程中的各种路径。适用于事件触发型业务流程，尤其适用于 NAS 中的文件操作、共享协作、多端同步和异步处理流程。

### 流程类型

| 流程类型 | 定义 | 优先级 |
|---------|------|--------|
| **基本流** | 最常见的正常操作路径（主成功场景） | P0 |
| **备选流** | 可接受的替代路径，最终仍能完成目标 | P1 |
| **异常流** | 错误处理路径，触发错误提示、回退、重试或降级 | P2 |

### 场景识别方法

1. **从需求中提取**：
   - 用户故事格式：`作为...我想要...以便于...`
   - 前置条件、后置条件
   - 流程步骤描述

2. **识别条件分支**：
   - `当...时`、`如果...则`、`否则`
   - `或者`、`也可以`
   - `失败时`、`超时后`、`错误情况`

3. **识别 NAS 特有流程变化**：
   - 文件状态：上传中、暂停、失败、完成、已删除、已恢复
   - 权限变化：授权、取消授权、权限降级、链接过期
   - 多端变化：一端操作、另一端刷新、离线恢复、冲突处理
   - 异步变化：索引中、转码中、AI 分析中、处理失败、降级展示

4. **流程图梳理**：
   - 绘制流程图标记所有分支
   - 每条路径生成一个场景
   - 对高风险分支补充异常流和恢复流

### 用例生成规则

| 场景类型 | 用例覆盖要求 |
|---------|-------------|
| 基本流 | 至少 1 条用例完整覆盖整个流程 |
| 备选流 | 基本流 + 该备选流分支 |
| 异常流 | 触发点 + 错误提示/回退/重试/降级/数据一致性验证 |
| 恢复流 | 中断、失败或冲突后，验证状态恢复与数据一致性 |
| 跨端流 | 一端操作后，验证另一端状态、权限、列表、搜索结果同步 |

### 示例：文件上传场景

```text
基本流：
  1. 进入目标目录
  2. 选择本地文件
  3. 点击上传
  4. 上传完成
  5. 文件出现在目标目录，名称、大小、修改时间、缩略图/预览状态正确

备选流1（同名文件处理）：
  基本流步骤 3 后 → 发现同名文件 → 选择覆盖 / 保留两者 / 取消 → 验证结果符合选择

备选流2（上传文件夹）：
  1. 选择本地文件夹
  2. 上传文件夹
  3. 验证目录层级、文件数量、文件大小保持一致

备选流3（弱网恢复）：
  上传过程中网络波动 → 上传暂停或重试 → 网络恢复 → 上传继续并完成

异常流1（容量不足）：
  上传开始前或上传过程中剩余容量不足 → 提示容量不足 → 不生成损坏文件

异常流2（断网中断）：
  上传过程中断网 → 展示失败/暂停状态 → 不产生错误完成态

异常流3（权限被取消）：
  上传过程中目录写权限被移除 → 上传失败 → 提示无权限 → 目录无残留异常文件

异常流4（索引延迟）：
  上传完成后立即搜索文件 → 若索引未完成，展示明确状态或稍后可搜索，不影响列表可见性
```

### 示例：共享链接场景

```text
基本流：
  1. 文件所有者创建分享链接
  2. 设置访问权限和有效期
  3. 访客打开链接
  4. 访客按权限预览或下载文件

备选流：
  - 设置提取码后访问
  - 修改有效期后访问
  - 取消分享后重新创建

异常流：
  - 链接过期
  - 提取码错误
  - 文件被删除
  - 分享权限被收回
  - 访客尝试执行超出权限的操作
```

### 示例：删除与回收站场景

```text
基本流：
  1. 用户删除文件
  2. 文件从原目录消失
  3. 文件进入回收站
  4. 用户从回收站恢复
  5. 文件回到原目录或指定目录

异常流：
  - 原目录已不存在
  - 原目录已有同名文件
  - 回收站保留期已过
  - 用户无恢复权限
  - 批量删除中部分文件失败
```

### 用例矩阵示例

| 场景ID | 场景名称 | 路径 | 优先级 |
|--------|---------|------|--------|
| SC_UPLOAD_01 | 上传单个文件成功 | 基本流 | P0 |
| SC_UPLOAD_02 | 上传同名文件选择保留两者 | 基本流 + 备选流1 | P1 |
| SC_UPLOAD_03 | 上传文件夹保持目录层级 | 备选流2 | P1 |
| SC_UPLOAD_04 | 弱网中断后上传恢复 | 基本流 + 备选流3 | P1 |
| SC_UPLOAD_05 | 容量不足时上传失败且无残留文件 | 基本流 → 异常流1 | P1 |
| SC_UPLOAD_06 | 权限取消后上传失败 | 基本流 → 异常流3 | P1 |
| SC_UPLOAD_07 | 上传完成后搜索索引延迟有明确状态 | 基本流 → 异常流4 | P2 |

## 4. 错误推测法 (Error Guessing)

### 定义

基于测试经验和产品风险，推测程序可能存在的缺陷位置，有针对性地设计测试用例。这是对其他方法的补充。

### 常见错误模式

#### 输入相关错误

| 错误类型 | 测试数据示例 |
|---------|-------------|
| 空值 | `null`、`undefined`、`""`、空格 |
| 特殊字符 | `' " < > & \\ / # @ ! $ % ^ * ( )` |
| 极端值 | `0`、`-1`、`MAX_INT`、超长字符串（1000+字符） |
| 格式错误 | 错误日期格式、无效邮箱、错误路径格式 |
| 注入攻击 | `' OR 1=1 --`（SQL）、`<script>alert(1)</script>`（XSS） |
| Unicode | 中文、日文、emoji、组合 Unicode 字符、不可见字符 |

#### 操作相关错误

| 错误类型 | 测试场景 |
|---------|---------|
| 重复提交 | 快速双击上传、删除、保存、分享按钮 |
| 并发操作 | 多窗口/多端同时操作同一文件或目录 |
| 操作中断 | 上传/下载/移动/删除过程中刷新页面、关闭客户端、断网 |
| 顺序颠倒 | 跳过必要步骤直接访问后续页面或接口 |
| 回退操作 | 操作完成后点击浏览器返回按钮或客户端返回上级目录 |
| 部分成功 | 批量操作中部分文件成功、部分文件失败 |

#### 数据相关错误

| 错误类型 | 测试场景 |
|---------|---------|
| 边界数据 | 第一条记录、最后一条记录、空目录、根目录 |
| 重复数据 | 同目录同名文件、重复标签、重复分享链接 |
| 关联数据 | 删除被分享、被收藏、被标签引用的文件 |
| 历史数据 | 旧版本文件、过期分享、回收站历史文件 |
| 空列表 | 无文件、无标签、无搜索结果、无共享成员 |
| 元数据不一致 | 文件内容更新后大小、修改时间、缩略图、搜索索引未同步 |

#### 环境相关错误

| 错误类型 | 测试场景 |
|---------|---------|
| 浏览器兼容 | Chrome、Firefox、Safari、Edge |
| 屏幕适配 | 移动端、平板、PC 各分辨率 |
| 弱网环境 | 高延迟、丢包、网络切换、断网后恢复 |
| 时区差异 | 分享有效期、修改时间、回收站保留期跨时区显示 |
| 客户端差异 | Pc / Web / Android / IOS 的能力差异与同步差异 |

#### NAS 云存储专属错误模式

| 错误类型 | 测试场景 |
|---------|---------|
| 容量不足 | 上传过程中剩余容量耗尽，验证失败提示和残留文件清理 |
| 磁盘异常 | 存储卷只读、离线、损坏或空间计算延迟 |
| 文件冲突 | 多端同时重命名、移动、删除同一文件 |
| 同名冲突 | 移动/恢复文件到已有同名文件的目录 |
| 元数据不一致 | 文件已更新但缩略图、大小、修改时间、标签未刷新 |
| 索引延迟 | 上传、删除、重命名后立即搜索文件 |
| 权限变更中断 | 操作过程中用户权限被移除或降级 |
| 分享失效 | 外链访问时文件被删除、移动、权限取消或链接过期 |
| 断点续传异常 | 分片上传失败、重复分片、分片顺序错乱、断点信息过期 |
| 批量部分失败 | 批量移动/删除/恢复中部分成功、部分失败，验证结果明细和可重试 |
| 多端同步冲突 | Pc 离线编辑后与 Web 端修改冲突，验证冲突提示和保留策略 |
| 回收站边界 | 文件过期自动清理后仍尝试恢复或访问 |
| 预览转码失败 | 视频、图片、PDF 转码失败后的降级展示 |
| 缩略图异常 | 缩略图生成失败但原文件可打开，列表不白屏 |
| AI/外部能力降级 | AI 分析超时、无结果、返回不稳定或服务不可用 |

### 示例：NAS 文件搜索错误推测

| 错误类型 | 测试场景 | 预期结果 |
|---------|---------|---------|
| 空值 | 搜索框为空点击搜索 | 按需求显示全部、空态或提示输入关键词 |
| 特殊字符 | 搜索 `%_*?/` 等特殊字符 | 正确转义，不报错，不误匹配 |
| 超长输入 | 输入 1000 个字符搜索 | 限制输入或提示超长，页面不崩溃 |
| XSS | 输入 `<script>alert(1)</script>` | 正确转义，不执行脚本 |
| 无结果 | 搜索不存在的文件名 | 显示无结果空态和可操作提示 |
| 大结果集 | 搜索热门词产生大量结果 | 分页/懒加载展示，响应时间可接受 |
| 空格处理 | 搜索词前后有空格 | 按需求裁剪或保留，结果一致可解释 |
| 权限过滤 | 搜索无权限目录下的文件名 | 不展示无权限文件 |
| 索引延迟 | 上传后立即搜索新文件 | 搜索状态与列表状态一致，必要时提示索引同步中 |
| 多端同步 | Pc 上传文件后 Web 端搜索 | 同步完成后可搜索，延迟状态有明确反馈 |

## 补充方法：状态迁移测试

状态迁移测试适用于对象存在明确生命周期或状态变化的需求。它不替代核心 4 法，而是辅助场景法识别完整流程、异常路径和恢复路径。

### NAS 常见状态机

| 对象 | 状态流转 |
|------|----------|
| 文件上传 | 待上传 → 上传中 → 暂停 → 上传失败 / 上传成功 |
| 文件下载 | 待下载 → 下载中 → 暂停 → 下载失败 / 下载成功 |
| 文件删除 | 正常 → 已删除 → 回收站 → 已恢复 / 已彻底删除 |
| 分享链接 | 未创建 → 已创建 → 已访问 → 已过期 / 已取消 |
| 同步任务 | 待同步 → 同步中 → 冲突 → 已解决 / 同步失败 |
| AI 分析 | 待处理 → 处理中 → 成功 / 失败 / 超时降级 |
| 预览转码 | 待转码 → 转码中 → 可预览 / 转码失败 |

### 生成原则

1. 每个关键状态至少有 1 条用例覆盖进入条件。
2. 每个终态至少验证 1 次页面展示、数据状态和可继续操作性。
3. 每个异常状态必须验证用户可理解的提示、可恢复路径或降级展示。
4. 涉及文件数据状态时，必须验证列表、详情、搜索、容量统计、多端展示是否一致。

---

## 补充方法：数据流测试

数据流测试适用于文件、元数据、索引、缩略图、权限等数据在多个模块间流转的需求。NAS 产品中，很多缺陷不是单点功能失败，而是跨模块数据不一致。

### NAS 典型数据流

| 数据流 | 验证方向 |
|--------|----------|
| 上传文件 → 存储服务 → 元数据 → 文件列表 → 搜索索引 → 预览/缩略图 | 上传成功后列表、详情、搜索、预览、缩略图状态一致 |
| 删除文件 → 原目录移除 → 回收站展示 → 容量统计更新 → 搜索结果移除 | 删除后原目录不可见、回收站可见、容量和搜索结果符合规则 |
| 修改权限 → 成员列表更新 → 文件访问控制 → 分享链接访问结果变化 | 权限变更后不同角色访问结果即时生效 |
| 重命名/移动文件 → 路径索引更新 → 最近访问/收藏/标签引用更新 | 路径变化后关联入口不失效、不出现旧路径脏数据 |
| AI 分析 → 后台任务 → 结果入库 → 前端展示 | 超时、失败、无结果时有降级展示和可追踪状态 |

### 生成原则

1. 对核心文件操作，至少验证一个跨模块数据一致性场景。
2. 异步处理场景应验证处理中、成功、失败、超时四类结果。
3. 多端同步场景应验证操作端和观察端的数据状态一致。
4. 部分失败场景应验证成功/失败明细、可重试性和最终一致性。

## 方法组合策略

### 标准用例设计流程

```text
1. 等价类划分 → 识别输入、对象、角色、状态的有效/无效等价类
       ↓
2. 边界值分析 → 对长度、数量、容量、时间、层级、大小等边界进行测试
       ↓
3. 场景法     → 覆盖主要业务流程（基本流 + 备选流 + 异常流 + 恢复流）
       ↓
4. 错误推测   → 补充经验性、高风险、历史缺陷、并发/中断/降级场景
       ↓
5. 状态/数据流增强 → 对 NAS 高风险对象补充状态迁移与数据一致性验证
```

### 方法组合去重原则

- EP 已覆盖的普通有效输入，不再用 ST 单独生成同等验证目标用例。
- BVA 的边界点如已覆盖某个无效等价类，保留边界描述更明确的用例，避免重复。
- ST 基本流中已覆盖的主成功路径，不再以“正常场景”重复生成。
- EG 只补充高风险、异常、组合、历史缺陷场景，不重复覆盖普通错误输入。
- 状态迁移和数据流测试用于补充“状态变化”和“跨模块一致性”，不要重复生成只验证同一按钮点击结果的用例。
- 判断是否重复时，以**验证目标**而非**测试数据是否不同**为准。

### 覆盖优先级映射

| 优先级 | 覆盖内容 |
|--------|---------|
| **P0** | 基本流用例 + 核心有效等价类 + 核心文件操作主链路 |
| **P1** | 备选流用例 + 边界值 + 主要无效等价类 + 权限/共享/同步/数据一致性关键场景 |
| **P2** | 异常流用例 + 次要无效等价类 + 常见错误推测 + 降级和恢复场景 |
| **P3** | 边缘错误推测 + 低频兼容性 + 非关键体验类场景 |

### NAS 优先级提升提示

若用例涉及以下内容，默认优先级可上调一级，具体规则以 [TEST-PRIORITY.md](./TEST-PRIORITY.md) 为准：

- 文件数据完整性：丢失、损坏、重复、版本错乱、元数据不一致
- 权限与隐私安全：越权访问、分享范围错误、私有文件泄露
- 核心文件操作：上传、下载、预览、搜索、移动、删除、恢复
- 多端同步与共享协作：跨端可见性、成员权限变更、共享链接状态
- 大文件/批量/并发：断点续传、批量部分失败、并发冲突
- 外部或系统依赖：存储服务、索引服务、缩略图/转码、AI 能力、网络和设备状态

### 设计方法标记

生成用例时在 JSON 的 `设计方法` 字段标记：

- `EP` — 等价类划分
- `BVA` — 边界值分析
- `ST` — 场景法
- `EG` — 错误推测
- `State` — 状态迁移测试
- `DataFlow` — 数据流测试
- `EP+BVA` — 组合使用
- `ST+EG` — 场景法与错误推测组合使用

> 若下游平台暂只识别 `EP` / `BVA` / `ST` / `EG`，补充方法可写入 `备注`，或与主方法组合标记为 `ST` / `EG`。

## 自学习改进

每次生成后统计设计方法分布，写入 `generation-history.json`。若发现：

- 某类方法占比异常（如 EG > 30%）→ Phase 2.8 预览时提示调整
- 某模块历史上漏测特定方法 → 下次自动补充
- NAS 高风险模块长期缺少状态迁移或数据流验证 → 下次生成时主动补充
- 用户反馈“缺并发 / 缺同步 / 缺容量 / 缺权限” → 记录为 NAS 常见遗漏模式
